ANALYSIS FEATURES

主な分析機能とメリット

1. ナンピン層別・到達率分析

全取引の中で「1段目で決済された割合」「最大ナンピン段数まで達した回数」「各段数の平均含み損保有期間」を一覧表示。リスクの限界値が一目瞭然になります。

2. 曜日×時間帯 損益ヒートマップ

「どの時間帯に負けが集中しているか」「週末の持ち越しリスクは高いか」を色分けヒートマップと評価バッジ（S/A/B/C/D）で自動分析。稼働時間フィルタの参考に最適です。

3. 破綻・損切りログ抽出＆CSV化

強制ロスカット（close at stop）や手動損切りトレードだけをピンポイント抽出。損切りが発生した日時・ロット数・ドローダウン金額を一覧にし、CSV形式で一発ダウンロード可能です。

4. 買い(Buy)/売り(Sell)分離モード

両建てトレード全体だけでなく、「買いポジションのみ」「売りポジションのみ」にワンクリックで表示切替。片方向のトレンドに弱いパラメータを即座に発見できます。

HOW TO USE

使い方の 3 ステップ

1

MT4でバックテストを実行しレポートを保存

MT4のストラテジーテスターでバックテストを行い、結果画面で右クリック ➔「レポートの保存」を選択して `.htm` または `.html` ファイルをPCに保存します。

2

DVLab Analyzer にファイルをドロップ

下記の「分析ツールを起動する」ボタンを押して画面を開き、左側サイドバーのアップロードエリアにファイルをドラッグ＆ドロップします。

3

自動生成されたレポートでリスクをチェック！

わずか数秒で総合パフォーマンス、ナンピン層別データ、時間帯ヒートマップ、損切りログが自動生成されます。
